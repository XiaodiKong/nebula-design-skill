# Linear 营销页适配

用于开发者产品、产品研发工具、发布页与用户明确选择 Linear 风格的营销页面。

## 官方研究来源

- [Linear 官网](https://linear.app/)
- [Linear Features](https://linear.app/features)

研究日期：2026-07-30。以下内容是基于公开官网的非官方前端适配。

## 视觉规律

- 近黑背景贯穿页面，白色主标题与冷灰正文形成强对比。
- 顶部导航低噪声、字重轻，主 CTA 使用白色胶囊按钮。
- Hero 标题超大但不花哨，左对齐并留出大面积负空间。
- 产品截图与页面背景融为一体，通过极细边框、暗色面板和局部光晕建立深度。
- 动画偏慢、克制，常用于产品界面渐入、光线移动或层次揭示。
- 薰衣草蓝只作为局部焦点，不覆盖主标题或大面积背景。

## 营销页实现

- 使用 `#08090a` 左右的底色、近白标题、冷灰说明和非常细的半透明边框。
- 导航高度克制，链接使用 13–14px；主 CTA 为浅色胶囊。
- Hero 用一句锋利主张配一段短说明，产品证明紧随其后并占据主要横向空间。
- 功能区以分隔线和大画面组织，减少浮动白卡。
- 动画只表现层次与流程，必须支持 `prefers-reduced-motion`。
- 字体使用精密的现代无衬线回退；数值与快捷键可用等宽字体。

## 避免

- 不添加霓虹彩虹渐变、发光按钮或密集粒子。
- 不用多种高饱和颜色破坏低噪声氛围。
- 不把所有文字缩成灰色；标题、正文和禁用态仍需清楚区分。
