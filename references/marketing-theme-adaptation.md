# 营销场景主题路由

六套主题可以用于产品应用，也可以用于营销官网。主题保持同一品牌气质，但营销页应使用顶部品牌导航、更强的叙事节奏和更低的信息密度；不要照搬产品后台的侧栏与工具栏。

## 按选择读取

- Cal.com（默认）：读取 [marketing-theme-cal.md](marketing-theme-cal.md)。
- Clarity：读取 [marketing-theme-clarity.md](marketing-theme-clarity.md)。
- Notion：读取 [marketing-theme-notion.md](marketing-theme-notion.md)。
- Linear：读取 [marketing-theme-linear.md](marketing-theme-linear.md)。
- Claude：读取 [marketing-theme-claude.md](marketing-theme-claude.md)。
- OpenCode AI：读取 [marketing-theme-opencode.md](marketing-theme-opencode.md)。

只读取当前选择的主题文件。用户要求比较或制作切换器时才读取全部六份。

| 主题 | 营销页核心表达 | 主要产品证明 |
|---|---|---|
| Cal.com（默认） | 浅灰框架、白色大容器、直接注册 | 清晰产品 UI 与完整操作步骤 |

## 共用与隔离

官网和产品应用可以共享：

- 品牌主色、中性色、字体家族和插图语言。
- 基础间距、圆角、焦点环与状态语义。
- Logo、图标与产品截图规范。

两种表面应保持独立：

- 官网使用品牌导航、内容区块、转化 CTA 和页脚。
- 产品应用使用任务导航、用户与组织上下文、状态和操作反馈。
- 官网的超大标题和展示字体不能直接覆盖高密度表格正文。
- 产品应用的侧栏、面包屑和批量操作不能出现在普通营销首页。

## 选择规则

1. 用户没有指定主题时仍默认 Cal.com。
2. 先确定产品应用或营销官网，再应用主题；不要让主题反向决定表面。
3. 用户要求多风格方案时，使用相同文案、相同区块和相同产品证据比较六套主题。
4. 主题切换可以改变布局节奏、字体、CTA 形态、产品证明框架和装饰语言，但不能改变价值主张与主转化目标。
5. 这些风格是基于官方公开页面研究的非官方适配，不使用品牌 Logo、插画、客户名单或文案冒充官方页面。
