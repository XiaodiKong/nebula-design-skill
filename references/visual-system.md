# 共用视觉底线与 Clarity 主题

本文件定义所有主题共用的产品设计底线，并给出 Clarity 主题。Skill 的默认主题为 Cal.com；主题选择与其他视觉语言见 [theme-selection.md](theme-selection.md)。

## 设计原则

1. **清晰优先**：先建立阅读顺序、任务入口和状态含义。
2. **专业克制**：少渐变、少阴影、少大圆角、少装饰色。
3. **高效紧凑**：充分利用桌面空间，但不牺牲可读性和可点击性。
4. **语义稳定**：同一种颜色、状态和操作在全产品保持一致。
5. **数据友好**：数字对齐、单位明确、时间范围和更新时间可见。
6. **中文优先**：按中文长度设计，不把英文界面直接翻译后硬塞。

避免大屏科技蓝、玻璃拟态、荧光色、3D 图表、全页渐变、卡片海洋和无目的动画。

## 色彩

### 品牌与交互色

| 语义 | 色值 | 用途 |
|---|---:|---|
| Primary 6 | `#246BFD` | 主按钮、选中、链接、焦点 |
| Primary 5 | `#4A85FF` | 悬停 |
| Primary 7 | `#1B55D9` | 按下 |
| Primary 1 | `#EDF4FF` | 选中行、浅提示背景 |
| AI accent | `#6E5FF8` | AI 标识和局部入口 |
| AI subtle | `#F3F1FF` | AI 建议背景 |

一个页面通常只保留一个明确主操作。AI 紫蓝不能替代主系统蓝，也不能铺满页面。

### 中性色

| 语义 | 色值 |
|---|---:|
| 一级文字 | `#1D2129` |
| 二级文字 | `#4E5969` |
| 辅助文字 | `#86909C` |
| 禁用文字 | `#C9CDD4` |
| 页面背景 | `#F5F7FA` |
| 容器背景 | `#FFFFFF` |
| 悬停背景 | `#F7F8FA` |
| 弱分割线 | `#E5E6EB` |
| 强边框 | `#C9CDD4` |

### 状态色

| 语义 | 前景 | 浅背景 | 示例 |
|---|---:|---:|---|
| 成功 | `#00A870` | `#E8F7F1` | 已发布、运行成功 |
| 警告 | `#D97706` | `#FFF7E8` | 等待审批、即将到期 |
| 错误 | `#E5484D` | `#FFF0F0` | 失败、高风险、阻断 |
| 信息 | `#246BFD` | `#EDF4FF` | 处理中、待配置 |

状态色只表示业务状态。普通分类标签优先使用灰色或浅蓝色。不要只靠颜色区分状态，必须配合文字、图标或形状。

### 对比度

- 正文和关键控件达到 WCAG AA。
- 小号灰字不放在彩色或复杂背景上。
- 交互焦点使用可见的外轮廓，不仅改变背景色。
- 图表同时使用标签、线型或图案辅助辨识。

## 字体

Clarity 主题使用无衬线中英文字体组合。所有主题必须拆分正文、标题和代码三种角色；详细令牌、加载方式与中文回退规则见 [typography-system.md](typography-system.md)。

```css
font-family: var(--admin-font-body);
```

| 层级 | 字号 / 行高 | 字重 |
|---|---|---:|
| 页面标题 | `20px / 28px` | 600 |
| 区块标题 | `16px / 24px` | 600 |
| 正文、表格 | `14px / 22px` | 400 |
| 辅助文字 | `13px / 20px` | 400 |
| 标签 | `12px / 18px` | 500 |
| 重要指标 | `24px / 32px` | 600 |

- 大数字使用等宽数字特性：`font-variant-numeric: tabular-nums`。
- 标题描述业务对象和动作，避免“欢迎回来”等占用工作区的口号。
- 不用超大标题制造层级。

## 间距与尺寸

采用 4px 基础网格：

- `4px`：图标与文字的微间距。
- `8px`：强相关元素。
- `12px`：紧凑组件。
- `16px`：常规内容与容器内边距。
- `24px`：区块间距和页面横向留白。
- `32px`：少量大区块分隔。

推荐控件尺寸：

| 元素 | 紧凑 | 默认 | 宽松 |
|---|---:|---:|---:|
| 输入框、按钮 | 28px | 32px | 40px |
| 表格行 | 40px | 48px | 56px |
| 表头 | 36px | 40px | 48px |

默认使用 32px 控件和 40–48px 表格行。关键点击区域不得因视觉紧凑而低于可用尺寸；图标按钮需要明确命中区和 Tooltip。

## 布局

默认桌面骨架：

- 顶部全局栏：56px。
- 左侧导航：224px；折叠后 64px。
- 内容区左右留白：24px。
- 区块纵向间距：16px 或 24px。
- 复杂数据页不强制 1200px 居中，充分使用横向空间。
- 表单或阅读型详情可限制为 720–960px，避免超长行。

页面标题区通常为一行或两行：

- 左侧：面包屑、标题、简短说明。
- 右侧：一个主操作和少量次操作。
- 标题下方才放筛选、Tabs 或工作区。

当左侧导航已经提供产品级导航时，页面内部不要重复完整导航体系。

## 圆角、边框与阴影

| 元素 | 圆角 |
|---|---:|
| 按钮、输入框 | 6px |
| 标签 | 4px |
| 卡片、下拉菜单 | 8px |
| 弹窗 | 10px |
| 抽屉 | 0px |
| 头像 | 圆形 |

- 默认边框：`1px solid #E5E6EB`。
- 强调边框只用于聚焦、选中或输入错误。
- 普通内容容器默认无阴影。
- 下拉、Popover、悬浮工具条可使用 `0 8px 24px rgba(29, 33, 41, .10)`。
- 不用边框把每个小区域都框起来；优先使用间距和标题分组。

## 密度与响应式

默认是中等偏紧凑。允许用户为表格切换紧凑、默认、宽松三档，但同一工作区保持一致。

断点策略：

- `>= 1440px`：展示完整导航、筛选和主表格。
- `1024–1439px`：可折叠导航，次要筛选进入“更多筛选”。
- `768–1023px`：优先保留主任务；表格允许横向滚动或切换摘要列表。
- `< 768px`：只支持查看、审批、状态更新等轻操作；复杂创建和配置提示转到桌面端。

不要为了“响应式”把复杂表格机械变成几十张卡片。

## 图标与动效

- 使用同一套线性图标；常规 16px、导航 18px、重点 20px，线宽 1.5–2px。
- “发布、执行、提交审批、删除”等关键操作显示中文文字。
- 常规反馈动效为 120–200ms；抽屉 200–240ms。
- 只对状态变化、层级切换和操作结果使用动画。
- 尊重 `prefers-reduced-motion`。

## 暗色模式

Clarity、Cal.com、Notion、Claude 和 OpenCode AI 默认交付浅色；Linear 与 Palantir 默认交付暗色。实现暗色时使用语义令牌重新映射，不直接反转颜色；检查表格悬停、状态标签、图表、代码编辑器和弹层对比度。
