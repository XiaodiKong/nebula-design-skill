# OpenCode AI 风格：中后台适配

读取本文件时同时遵守 [visual-system.md](visual-system.md) 和 [typography-system.md](typography-system.md)。

## 风格定位

使用暖白画布、近黑文字、全局等宽字体、4px 小圆角和终端式分区，形成 README、man page 与 TUI 融合的开发者工具体验。视觉识别主要来自字体、ASCII 标记和线性边界，而不是装饰。

适合 AI 编码工具、研发平台、终端工作台、日志、构建发布和开发者门户。

## 核心令牌

| 语义 | 值 |
|---|---:|
| 主操作 / 近黑 | `#201D1D` |
| 主操作按下 | `#0F0000` |
| 页面背景 | `#FDFCFC` |
| 柔和表面 | `#F8F7F7` |
| 卡片表面 | `#F1EEEE` |
| 深色终端 | `#201D1D` |
| 一级文字 | `#201D1D` |
| 正文 | `#424245` |
| 辅助文字 | `#646262` |
| 可访问信息蓝 | `#0062CC` |

实现时使用 [assets/opencode-tokens.css](../assets/opencode-tokens.css)。

## 字体

- 原始风格所有文字使用 Berkeley Mono。
- 没有商业授权时，英文使用 JetBrains Mono、IBM Plex Mono、Geist Mono 或系统等宽字体。
- 中文使用 Sarasa Mono SC、Noto Sans Mono CJK SC，再回退到苹方或微软雅黑。
- 页面标题、正文、按钮、导航、表格和代码都使用同一等宽家族；只通过字号、字重和行高建立层级。
- 中文正文行高至少 1.6，避免等宽字体造成拥挤。

## 页面骨架与组件

- 页面主体是暖白画布；侧栏或代码区可使用近黑终端表面。
- 普通区域通过 1px 细线和间距分组，不创建漂浮卡片。
- 交互控件统一 4px 圆角，主按钮近黑底暖白字。
- 标签和列表可使用 `[+]`、`[-]`、`[x]` 等 ASCII 前缀，但关键操作仍保留清楚中文。
- 表格、日志和技术元数据天然适合等宽字体；长中文字段仍需设置合理列宽和截断。
- 不使用阴影、渐变、插画和大圆角。

## 图形工作台

- 节点像终端或配置块：暖白/浅灰底、细边框、4px 圆角。
- 关系边使用近黑或中灰；激活链路使用信息蓝。原始亮蓝 `#007AFF` 仅用于能达到 3:1 的非文本强调；普通文字使用较深的 `#0062CC`。
- 节点状态可以配合 `[ok]`、`[warn]`、`[err]` 文本标记，颜色不是唯一线索。
- 深色终端详情面板可用于日志、命令、堆栈和执行结果。
- 关系标签、对象 ID 和端口名使用等宽字体；中文业务描述保持足够行高。

## 避免

- 不把 OpenCode 误做成霓虹黑客风。
- 不使用多套比例字体破坏全局等宽识别。
- 不使用卡片阴影、玻璃拟态或圆润胶囊作为主要组件。
- 不为了 ASCII 风格牺牲可访问名称、中文可读性或按钮语义。
