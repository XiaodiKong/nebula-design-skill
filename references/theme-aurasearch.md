# AuraSearch 产品应用主题

AuraSearch 主题来自用户提供的 `13AuraSearch – AI Visibility & Generative Engine Optimization SaaS UI Kit.fig`。它是一套面向 AI 可见性、分析与运营场景的双模式 SaaS 产品语言：浅紫中性画布、白色或近黑大圆角表面、紫色主操作、彩色指标轨道，以及紧凑但不拥挤的图表与表格。

这里只沉淀可复用的令牌、布局和组件模式，不复制原始 Logo、插画、品牌文案、图片或完整画板。它是本 Skill 的 AuraSearch 适配，不代表原设计作者或 Figma 的官方设计系统。

## 来源快照

本地解析与 Figma 画板核对得到：

- 56,020 个节点，包含 377 个变量、31 个变量集、6 个页面画布。
- 产品页包含 36 个浅色画板和 36 个暗色画板，覆盖仪表盘、项目、AI 引擎、可见性、Prompt Explorer、排名、竞品、提及、机会、报告、设置与认证。
- 组件页覆盖按钮、侧栏、输入、选择、开关、复选框、单选、状态标签、顶部工具和表单反馈。
- 主品牌色为 `#9348FC`，页面中性背景为 `#F8F7FE`，核心正文为 `#050D1F`。
- 主要英文界面使用 Helvetica Neue 与 Inter。主题只声明字体栈，不分发字体文件。

## 适合场景

- AI 分析、LLM 监控、模型评估与可观测性产品。
- BI、增长、运营、SEO/GEO 与多引擎比较工作台。
- 需要仪表盘、筛选表格、主从详情和多系列图表的 SaaS 产品。
- 希望浅色与暗色保持同一组件几何的完整系统应用。

不适合默认用于纯内容编辑器、传统政务门户、极端紧凑的交易终端或强调硬朗工业感的任务控制台。

## 视觉 DNA

1. 页面背景弱于所有业务容器，浅色使用带紫倾向的 `#F8F7FE`。
2. 侧栏、卡片、图表和表格用白色或近黑独立表面，不使用厚重投影。
3. 24px 大圆角建立整体亲和力；控件通常为 12px 或胶囊形。
4. 紫色只承担品牌动作、当前选中和关键趋势；青、洋红、黄、橙用于真实状态或图表序列。
5. 信息密度来自清楚分组、紧凑字阶和稳定栅格，不来自缩小所有文字。
6. 图表、指标卡和表格同时出现时，通过白色表面与 16px 间距维持秩序。

## 页面模式

### 分析仪表盘

推荐顺序：

1. 全局结果 Hero：核心变化、证据句、主次操作和 2–3 个关键摘要。
2. 3–4 个指标卡：使用细色轨或小图标，而不是整卡着色。
3. 主趋势图 + 份额/构成图。
4. 竞品基准 + 排名表格。

Hero 可以使用低对比点阵或紫色光晕，但正文与按钮必须在独立可读层上。指标卡高度保持一致，数字使用 32–40px，单位和解释紧邻数字。

### 列表 + 详情

Prompt Explorer 一类页面使用：

- 左侧或主列：搜索、胶囊筛选、表格、分页。
- 右侧详情：对象标题、分类标签、4 个关键指标、正文结果、来源与操作。
- 主从列之间固定 16px 间距；详情面板保持独立白色表面。
- 行选中使用 `--admin-color-primary-subtle`，保留复选框、状态和引擎图标。

窄屏时把详情改为抽屉或页面内下钻，不把两列强行缩到手机宽度。

### 设置与计费

- 设置分类使用大胶囊标签栏，当前项有浅紫背景。
- 计费卡可以三列比较，但只高亮一个推荐方案。
- 套餐价格、周期、功能列表和主操作保持同一阅读顺序。
- 使用量用有文字标签的进度轨表达；进度颜色不能独自表示好坏。

## 组件表面

### 导航项

- 高度 40–44px，图标位于低对比圆形底上。
- 当前项使用浅紫背景和深色文字，不能整条使用高饱和紫底。
- 一级分组标题使用 11–12px 大写或弱化文本；中文不强制大写效果。

### 按钮

- 主按钮：紫色渐变或纯 `#9348FC`，白字，40–48px 高。
- 次按钮：白色/暗色表面、1px 边界、正文色。
- 危险按钮使用危险语义色，不复用品牌紫。
- 纯图标按钮必须有可访问名称和明确悬停背景。

### 卡片与指标

- 普通卡片使用 16–24px 内边距、24px 圆角、弱边界或无边界。
- 只在卡片确实代表独立任务或数据组时使用卡片；避免容器层层嵌套。
- 指标类别优先用文字和图标，左侧 3–4px 色轨可以作为辅助编码。

### 表单

- 输入、选择和搜索框使用 40–48px 高、12px 或胶囊圆角。
- 默认、聚焦、错误、成功、禁用和只读状态必须完整。
- 提示与错误信息位于控件下方，不能只改变边框颜色。

### 表格

- 表头 12–14px，正文 14px；数字列右对齐。
- 行高建议 52–56px，复选框和菜单拥有独立点击区。
- 选中行使用浅紫背景；悬停比选中更弱。
- 在高密度场景减少圆角和卡片，而不是降低正文可读性。

## 字体

主题令牌使用：

- 英文正文与标题：`Helvetica Neue` → `Inter` → 系统无衬线。
- 中文正文与标题：`PingFang SC` → `HarmonyOS Sans SC` → `Noto Sans SC`。
- 技术元数据：`JetBrains Mono` → 系统等宽 → 中文等宽回退。

推荐字阶：

| 角色 | 字号 / 行高 | 字重 |
|---|---|---|
| 页面大标题 | 32/40 | 500–600 |
| 区块标题 | 18/24 | 500–600 |
| 正文与表格 | 14/20 | 400–500 |
| 辅助文字 | 12/16 | 400 |
| 指标数字 | 32/40 或 40/48 | 500–600 |

中文不要沿用英文负字距。混排页面使用 `--admin-font-body` 与 `--admin-font-display`，不要直接硬编码 Helvetica Neue。

完整令牌见 [assets/aurasearch-tokens.css](../assets/aurasearch-tokens.css)。核心角色：

| 角色 | 浅色 | 暗色 |
|---|---|---|
| 页面 | `#F8F7FE` | `#09090B` |
| 表面 | `#FFFFFF` | `#16161A` |
| 正文 | `#050D1F` | `#F0EFEE` |
| 次级文字 | `#545454` | `#DFDFDF` |
| 边界 | `#DFDFDF` | `#242629` |
| 品牌主色 | `#9348FC` | `#9348FC` |
| AI | `#D500BB` | `#D500BB` |

AI 分析产品经常需要多系列色。只有 `data-emphasis` 图表区域可以同时使用紫、青、洋红、黄、橙和蓝；导航、普通标签和对象类型继续保持中性。

## 暗色模式

在主题样式表加载后设置：

```html
<html data-admin-theme="aurasearch" data-admin-mode="dark">
```

暗色模式保持 16/24px 几何、组件尺寸和信息顺序不变，只替换语义令牌。不要使用 `filter: invert()`；图表网格、边界、禁用态、悬停和浮层要单独检查。

## 图形与关系工作台

- 使用浅紫或近黑画布，节点默认保持中性表面。
- 关系状态沿用 `assets/semantic-state-tokens.css`，不要把紫、青、洋红全部解释为风险等级。
- 选中节点使用紫色外环或浅紫底，同时保留错误/警告状态点。
- 详情面板可复用“列表 + 详情”模式，宽度建议 320–400px。
- 数据系列色只用于图表、线路或图例，并提供文字标签。

## 验收清单

- 1440px 下外边距、侧栏、主区和 24px 间距形成稳定几何。
- 1024px 下侧栏可折叠，主表格和详情不会互相挤压。
- 390px 下导航变为抽屉，主要动作不被固定栏遮挡。
- 浅色与暗色拥有相同主路径、焦点顺序和状态含义。
- 图表色不冒充成功、警告或危险状态。
- 字体缺失时仍能稳定回退，中文按钮和表头不截断。
- 不把原始 AuraSearch Logo、示例用户、商业数字或界面文案当作通用素材复制。
