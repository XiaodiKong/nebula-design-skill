# Linear 风格：产品应用适配

读取本文件时同时遵守 [visual-system.md](visual-system.md) 和 [typography-system.md](typography-system.md)。

## 风格定位

使用近黑画布、分级炭黑表面、细边框和单一薰衣草蓝强调，形成低噪声、精密、偏工程工具的暗色工作区。层级主要依靠明度与边框，而不是阴影或多种品牌色。

适合研发管理、自动化、运维、技术配置和暗色图形工作台。默认是暗色主题，用户要求浅色时不要仅做颜色反转，应重新选择 Clarity、Cal.com 或 Notion。

## 核心令牌

| 语义 | 值 |

| 页面画布 | `#010102` |

| 二级表面 | `#141516` |

实现时使用 [assets/linear-tokens.css](../assets/linear-tokens.css) 并设置 `color-scheme: dark`。

## 排版

- 英文标题使用 Linear Display；缺少合法字体资产时用 `SF Pro Display`、Inter 或系统无衬线。
- 中文标题和正文使用 Noto Sans SC、思源黑体、苹方或微软雅黑。
- 英文正文使用 Linear Text、`SF Pro Text` 或 Inter。
- 标题 500–600，并使用轻微负字距；正文保持 400–500。
- 中后台页面标题保持 20–28px，避免把营销页 80px 标题带入产品界面。
- ID、版本、状态和技术元数据可使用系统等宽字体。

## 页面骨架

- 侧边栏与画布只相差一到两个明度层级；当前项用更亮表面和紫色细标记。
- 顶栏使用一级表面与细边框，不使用透明玻璃模糊。
- 卡片通常是 `#0F1011` 或 `#141516`，1px 边框，6–12px 圆角。
- 阴影接近零；弹层依靠更亮表面、强边框和遮罩建立层级。
- 信息密度可以偏高，但保持稳定的 4px 间距节奏和清楚的行高。

## 组件

- 主按钮：薰衣草蓝底白字，6–8px 圆角。
- 次按钮：一级表面、浅色文字、细边框。
- 输入框：二级表面、强边框；聚焦使用紫色外环。
- 标签：以中性暗色为主；成功、警告、错误色只出现在状态点、标签和关键文字。
- 表格：弱分割线、明显行悬停；选中行使用极浅紫色叠层。
- 弹层：二级或三级表面、强边框，不使用大面积紫色光晕。

## 图形工作台

- 画布使用 `#010102` 或 `#0F1011`，网格点使用 `#23252A`。
- 节点使用一级表面，边框采用 hairline；节点选中使用 `#5E6AD2`。
- 普通关系边使用 `#62666D`，激活边使用薰衣草蓝。
- 分组通过轻微表面明度差与虚线边框表示，不使用彩色大底。
- 业务分组色降低饱和度；错误、警告和成功仍保留可识别语义。

## 避免

- 不增加第二个装饰性品牌色。
- 不使用彩色渐变、霓虹光效、玻璃拟态或厚重阴影。
- 不把所有文字都设为纯白；用四级文字明度建立层级。
- 不把紫色用于普通正文、所有图标或全部关系边。
