# Cal.com 风格：中后台适配

读取本文件时同时遵守 [visual-system.md](visual-system.md) 的业务可用性与状态完整性要求。

## 风格定位

使用白色画布、黑色主操作、浅灰功能表面和充足留白，形成友好、现代、工程化的 SaaS 工作区。品牌感来自排版、黑白对比和真实产品界面，不来自大面积装饰色。

适合预约、表单、客户成功、轻量 CRM 和流程工具。数据密集页面仍需保持列对齐与扫描效率，不能为了留白降低可用信息量。

## 核心令牌

| 语义 | 值 |
|---|---:|
| 主操作 | `#111111` |
| 主操作悬停 | `#242424` |
| 页面 / 容器 | `#F8F9FA` / `#FFFFFF` |
| 浅卡片 | `#F5F5F5` |
| 一级文字 | `#111111` |
| 正文 | `#374151` |
| 辅助文字 | `#6B7280` |
| 边框 | `#E5E7EB` |
| 稀有链接强调 | `#3B82F6` |

实现时使用 [assets/cal-tokens.css](../assets/cal-tokens.css)，不要在组件内重复十六进制色值。

## 排版

- 标题优先使用 `Cal Sans`；缺少合法字体资产时用 Inter 600 并设置轻微负字距。
- 正文、表格、按钮和导航使用 Inter 或系统无衬线。
- 中后台页面标题保持 `20–28px`，不要照搬营销页的超大展示字号。
- 按钮文字使用 14px / 600；数字使用等宽数字特性。

## 页面骨架

- 侧边栏使用白色或极浅灰，与内容区通过细边框区分。
- 当前导航项可使用黑底白字；普通悬停使用浅灰底。
- 顶栏保持白色、64px 以内，不使用大面积品牌色。
- 内容容器可使用浅灰卡片分区；同一层级不重复套卡片。
- 控件默认 36–40px，圆角 8px；内容卡片圆角 12px。

## 组件

- 主按钮：黑底白字，8px 圆角，不加渐变和发光。
- 次按钮：白底黑字、1px 边框。
- 输入框：白底、细边框；聚焦时边框变黑并保留外部焦点环。
- 标签：中性灰为主；彩色仅用于类别或业务状态。
- 卡片：`#F5F5F5` 或白底细边框，通常无阴影。
- 分段选择：浅灰胶囊容器内嵌白色活动项，可使用极弱阴影。

## 图形工作台

- 画布白色或 `#F8F9FA`，网格极弱。
- 节点使用白色，选中态用黑色或稀有蓝色描边。
- 关系边以中灰为主，激活链路可使用 `#3B82F6`。
- 工具栏使用黑白控件，不把不同图形分组都染成品牌蓝。

## 避免

- 不使用深蓝企业侧边栏。
- 不把蓝色作为所有按钮和选中项的默认颜色。
- 不使用玻璃拟态、彩色渐变或厚重阴影。
- 不把营销页 96px 区块留白机械套入数据后台。
