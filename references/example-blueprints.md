# 示例蓝图

这些蓝图用于帮助选择信息架构，不是固定文案或数据库模型。根据真实业务调整。

## 客户画像管理

**角色**：客户运营、风险分析师。

**主任务**：定位客户、判断风险与活跃度、查看画像、批量分群。

页面结构：

1. 标题“客户画像”和说明；主操作“新建画像”。
2. 搜索客户名称/统一信用代码；客户类型、风险等级、负责人、更多筛选。
3. 可选指标：客户总数、高风险客户、今日更新；点击指标可形成筛选。
4. 表格：客户名称、类型、风险等级、关键标签、负责人、更新时间、操作。
5. 详情抽屉：基础信息、风险概览、标签、行为时间线、关联关系、特征数据、决策记录。

关键状态：

- 特征数据过期。
- 标签计算中或失败。
- 敏感字段脱敏且按权限查看。
- 批量分群说明范围与预计耗时。

## 风控策略配置

**角色**：策略运营、风险专家、审批人。

**主任务**：构建规则、测试样本、评估影响、提交审批并发布。

推荐三栏工作台：

- 左：规则组件、变量、已保存模块。
- 中：规则树或流程画布。
- 右：当前节点属性、校验、影响说明。
- 顶：策略名称、草稿状态、版本、保存、测试、提交审批。
- 底：问题列表、样本命中结果、运行日志。

关键状态：

- 未保存变更、语法错误、变量失效。
- 样本测试进行中、部分失败、无命中。
- 发布前展示影响客户数、变化率和回滚版本。
- 审批人只读并能查看差异。

## 数据研发任务

**角色**：数据工程师、任务运维。

**主任务**：创建任务、配置依赖、运行、定位失败、查看血缘影响。

列表页字段：

- 任务名称、类型、负责人、调度周期、当前状态、最近运行、耗时、SLA、操作。

详情页：

- 概览：状态、下次运行、负责人、资源组。
- Tabs：代码/配置、依赖关系、运行实例、日志、血缘、变更记录。
- 失败实例优先显示错误摘要、失败节点、受影响下游和重跑入口。

关键状态：

- 排队、运行、成功、失败、暂停、已下线。
- 重跑需明确从失败节点还是全量执行。
- 修改依赖或产出表时展示下游影响。
- AI 可生成 SQL 草稿和解释错误，但发布和重跑由用户确认。

## 权限管理

**角色**：系统管理员、业务管理员、审计人员。

**主任务**：理解谁拥有什么权限、授予或回收权限、审计异常访问。

信息架构：

1. 角色、用户组、成员、资源权限四个相关视图。
2. 角色列表展示成员数、权限范围、来源、更新时间。
3. 角色详情包含基本信息、成员、资源权限、继承关系、变更记录。
4. 授权流程先选择主体，再选择资源和权限，最后确认范围与有效期。

关键状态：

- 继承权限和直接权限视觉区分。
- 系统角色不可删除并说明原因。
- 回收权限前显示受影响成员、资源和正在运行的任务。
- 敏感权限需要审批、有效期和审计理由。
- 无权限用户看不到敏感详情，但能看到申请入口。
