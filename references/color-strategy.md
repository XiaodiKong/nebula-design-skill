# 颜色策略

颜色策略决定“颜色承担什么信息”，主题决定“颜色长什么样”。两者必须独立选择：Cal.com、Linear、Palantir 等主题都可以采用 Monochrome First；任何主题都不能覆盖错误、警告、成功等受保护状态语义。

## 先选择策略

| 策略 | 默认场景 | 颜色职责 |
|---|---|---|
| `monochrome-first` | Flow、DAG、关系图、数据血缘、架构图、AI IDE、高密度后台 | 界面和类型保持中性；颜色只强调状态、关键动作、AI 与少量数据 |
| `brand-led` | 营销官网、品牌发布页、低密度轻应用 | 品牌色可建立叙事节奏，但不能冒充业务状态 |
| `data-emphasis` | BI、监控、分析、科学与运营图表 | 多系列色只存在于数据可视化区域，不扩散到导航、卡片或分类标签 |

默认决策：

1. 技术工作台、复杂图形、密集数据页面使用 `monochrome-first`。
2. 营销官网使用 `brand-led`，当页面包含复杂产品截图或图表时，截图内部仍可使用另外两种策略。
3. 数据比较是核心任务且需要区分三个以上系列时使用 `data-emphasis`。
4. 用户没有指定策略时，先按表面和任务选择；不要根据主题名称推断策略。

## Monochrome First

界面主体使用黑、白、灰或主题对应的中性色：

- 页面、导航、卡片、分组和默认节点使用中性色。
- 主要动作可以使用主题主色；选中态优先使用高对比中性描边或焦点环。
- 运行中使用蓝色，成功使用绿色，警告使用橙色，错误使用红色。
- AI 建议和生成内容使用独立 AI 色，并配“AI 建议”“需确认”等文字。
- 图形类型使用图标、短代码、形状、标题、分组或位置表达，不为每类随机分配颜色。
- 普通分类标签保持中性；只有真实状态标签使用语义色。

## 信息编码顺序

优先按以下顺序表达差异：

1. 位置、分组和阅读顺序。
2. 文字标签与短代码。
3. 图标、形状和尺寸。
4. 边框、线型和纹理。
5. 颜色。

颜色不能成为唯一线索。去掉颜色后，用户仍应能判断对象类型、关系方向、选择位置和操作结果。

## 状态冲突处理

一个对象可能同时具有类型、运行状态、搜索命中和选中状态。按下表分配不同视觉通道：

| 语义 | 首选表达 | 颜色规则 |
|---|---|---|
| 对象类型 | 图标、短代码、形状、分组 | 默认中性 |
| 执行或业务状态 | 状态点、图标、文字标签、细侧轨 | 使用受保护状态色 |
| 选中 | 强中性边框与焦点环 | 不覆盖状态点 |
| 搜索命中 | 轻背景、文字高亮或外环 | 不覆盖选中与错误 |
| 禁用 | 禁用文字、图标和原因 | 可降低对比，但不只靠透明度 |
| 关系类型 | 实线、虚线、箭头和文字 | 默认中性 |
| 活动或故障路径 | 加粗、流向和状态色 | 仅高亮当前路径 |

同时出现时，状态点或状态标签始终保留。例如一个“已选中的失败节点”使用中性选中边框，同时保留红色错误点和“失败”文字。

## 数据可视化

- 普通系列不要复用成功、警告、错误色，否则用户会误读数值好坏。
- 系列顺序必须稳定，并提供图例、直接标注或文本替代。
- 红绿表达状态时，再增加图标、文字、线型或纹理。
- 趋势色只用于真正有方向含义的数据；不要把所有上涨都解释为成功。
- 图表色不扩散到页面导航、容器背景或普通分类标签。

## 令牌与加载顺序

先加载已选主题令牌，再加载 [assets/semantic-state-tokens.css](../assets/semantic-state-tokens.css)：

```html
<link rel="stylesheet" href="./assets/cal-tokens.css">
<link rel="stylesheet" href="./assets/semantic-state-tokens.css">
```

组件优先使用 `--nebula-*` 角色变量。已有设计系统时，把这些变量映射到现有令牌，不重复维护另一套颜色值。

## 可访问性与暗色主题

- 正文、状态文字、控件边界和焦点环都要在实际背景上检查对比度。
- 状态点旁提供文本或图标；小色块不能独自传达错误或成功。
- 暗色主题不要简单反转颜色；分别检查弱边框、禁用态、网格、连线和浮层。
- 支持 `forced-colors` 时，保留边框、轮廓和系统色；不要依赖背景渐变。
- 使用 `prefers-reduced-motion` 降低运行流线和脉冲动画。

## 验收问题

- 去除颜色后，类型、层级、关系和选中是否仍可理解？
- 错误、警告、运行和成功是否在所有主题下保持一致含义？
- 选中、搜索命中和状态同时出现时是否互不覆盖？
- 普通分类或数据系列是否误用了状态色？
- 颜色是否集中在真正需要用户注意的位置？
